Cloud Engineer

Builds and maintains systems that run on AWS, Azure, or Google Cloud.

On this page

  • Overview
  • Daily responsibilities
  • Required skills
  • Tools used
  • Salary range
  • Career path
  • Certifications

Overview

Cloud engineers design, deploy, and look after the servers, storage, and networks that companies rent from cloud providers instead of owning. Their goal is systems that stay online, stay secure, and cost less to run.

Daily responsibilities

  • Deploy and configure cloud resources
  • Monitor performance and fix outages
  • Automate repetitive setup with scripts
  • Review security settings and costs

Required skills

  • Linux command line
  • Networking basics (IP, DNS, firewalls)
  • One cloud platform (AWS, Azure, or GCP)
  • Scripting in Python or Bash
  • Clear written documentation

Tools used

  • AWS Console / Azure Portal
  • Terraform
  • Docker
  • Git and GitHub

Salary range

Cloud engineers are not a separate category in U.S. government data. Related roles (network and systems administrators, software developers) typically earn between about $70,000 and $140,000 per year, depending on experience and location. See the U.S. Bureau of Labor Statistics Occupational Outlook Handbook for current figures.

Career path

  1. Help desk or IT support
  2. Junior cloud or systems administrator
  3. Cloud engineer
  4. Senior cloud engineer or cloud architect

Certifications

  • CompTIA Network+
  • AWS Certified Cloud Practitioner
  • Microsoft Azure Fundamentals (AZ-900)
  • AWS Solutions Architect Associate
