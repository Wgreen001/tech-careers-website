Network Technician

Installs, tests, and repairs the equipment that keeps devices connected.

On this page

  • Overview
  • Daily responsibilities
  • Required skills
  • Tools used
  • Salary range
  • Career path
  • Certifications

Overview

Network technicians set up and maintain routers, switches, cables, and wireless access points. When someone cannot get online, they find out why and fix it.

Daily responsibilities

  • Install and test network hardware
  • Troubleshoot connection problems
  • Replace faulty cables and devices
  • Update documentation and network diagrams

Required skills

  • TCP/IP, DNS, and DHCP
  • Cabling and hardware
  • Troubleshooting step by step
  • Reading network diagrams
  • Customer service

Tools used

  • Routers and switches
  • Cable testers
  • Ping, traceroute, and ipconfig
  • Network monitoring software

Salary range

Network support roles typically earn between about $50,000 and $90,000 per year, rising with experience and certifications. See the U.S. Bureau of Labor Statistics Occupational Outlook Handbook for current figures.

Career path

  1. Help desk technician
  2. Network technician
  3. Network administrator
  4. Network engineer

Certifications

  • CompTIA A+
  • CompTIA Network+
  • Cisco CCNA
