Cybersecurity Analyst

Watches for threats and protects systems and data from attack.

On this page

  • Overview
  • Daily responsibilities
  • Required skills
  • Tools used
  • Salary range
  • Career path
  • Certifications

Overview

Cybersecurity analysts monitor networks and systems for suspicious activity, investigate alerts, and help organizations fix weaknesses before attackers find them.

Daily responsibilities

  • Review security alerts and logs
  • Investigate possible incidents
  • Run vulnerability scans
  • Recommend and apply security fixes

Required skills

  • Networking fundamentals
  • Operating system security
  • Reading logs and spotting patterns
  • Risk awareness
  • Calm communication under pressure

Tools used

  • SIEM tools such as Splunk
  • Wireshark
  • Vulnerability scanners such as Nessus
  • Firewalls and endpoint protection

Salary range

U.S. government data lists information security analysts with a typical median pay of roughly $120,000 or more per year. Entry-level roles usually start lower. See the U.S. Bureau of Labor Statistics Occupational Outlook Handbook for current figures.

Career path

  1. Help desk or network support
  2. SOC (security operations center) analyst
  3. Security analyst
  4. Security engineer or incident responder

Certifications

  • CompTIA Security+
  • CompTIA CySA+
  • (ISC)2 Certified in Cybersecurity
  • CISSP (after several years of experience)
