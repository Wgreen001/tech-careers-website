Software Developer

Designs, writes, and tests the programs and websites people use.

On this page

  • Overview
  • Daily responsibilities
  • Required skills
  • Tools used
  • Salary range
  • Career path
  • Certifications

Overview

Software developers turn ideas into working applications. They write code, test it, fix bugs, and work with teammates to ship features.

Daily responsibilities

  • Write and review code
  • Test and debug programs
  • Plan features with teammates
  • Use Git to track and share changes

Required skills

  • A language such as Python, JavaScript, or Java
  • Problem solving
  • Git and version control
  • Reading other people's code
  • Teamwork

Tools used

  • VS Code
  • Git and GitHub
  • Terminals and command line
  • Testing frameworks

Salary range

U.S. government data shows software developers with a typical median pay above $120,000 per year. Entry-level salaries are lower and vary widely. See the U.S. Bureau of Labor Statistics Occupational Outlook Handbook for current figures.

Career path

  1. Junior developer or intern
  2. Software developer
  3. Senior developer
  4. Tech lead or software architect

Certifications

  • OCJP or OCJDA (Java)
  • PCEP or PCAP (Python)
  • AWS Certified Developer Associate
  • PMI Project Management Professional
